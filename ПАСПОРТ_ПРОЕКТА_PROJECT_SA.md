## 1. КОНЦЕПЦИЯ, ФИЛОСОФИЯ И ЛОР

**PROJECT S-A TERMINAL (Проект С-А)** — это автономное специализированное веб-приложение (**Telegram Mini App / TMA**), созданное на стыке **советской кибернетики закрытых НИИ**, **аналогового ретрофутуризма (Cassette Futurism)**, **биохакинга** и **радикального анти-дофамина**.

### 1.1. Философия системы
1. **Анти-дофаминовый подход:** Интерфейс не развлекает, не устраивает «праздник конфетти» и не провоцирует компульсивный скролл. Он дисциплинирует, собирает телеметрию и калибрует состояние оператора.
2. **Терминология контура:**
   - **Оператор** — человек, синхронизированный с терминалом через 4-значный ключ доступа.
   - **Био-датчик** — физическое тело и нервная система Оператора.
   - **Контур** — замкнутая цепь взаимного наблюдения и обратной связи.
   - **Гримуар** — база оперативных карточек и протоколов (Соматика, Когнитивистика, Изоляция).
   - **Инцидент b181** — универсальный код аномалий, сбоев или закрытых протоколов очистки.
   - **Талая вода** — процесс фракционного вымораживания дейтерия для биологической перезагрузки клеточной матрицы.
3. **Эстетика 1-Bit / E-Ink:**
   - Строгий брутализм, отсутствие скруглений (`border-radius: 0px`).
   - Моноширинные шрифты (`Fira Code`, `Space Mono`).
   - Прямоугольные фреймы, ASCII-символика (`[ ]`, `■`, `═══`, `───`).
   - Две контрастные темы: **Тёмная консоль** (`#0a0a0a`) и **Светлая электронная бумага (E-Ink)** (`#f5f5f0`).

## 2. АРХИТЕКТУРА И СТЕК ТЕХНОЛОГИЙ

```
project-sa-terminal/
├── backend/            # Fastify REST API + SQLite (Node.js)
│   ├── src/
│   │   ├── db/         # Схема TERMINAL_DB, сиды категорий и карточек
│   │   └── routes/     # categories, cards, auth, operators, messages
│   └── index.js        # Точка входа сервера (порт 3000)
├── bot/                # Telegram-бот (Python 3 + Aiogram 3)
│   └── main.py         # Обработка /start и запуск WebApp
├── frontend/           # Клиентская часть (Vanilla JS, Canvas 2D, CSS)
│   ├── index.html      # Одностраничное терминальное SPA
│   ├── style.css       # Монохромные терминальные стили + E-Ink
│   ├── app.js          # Ядро интерфейса, навигация, инструменты, заметки
│   ├── terrarium.js    # Графический движок питомца + физика тамагочи
│   └── assets/         # Исходные визуальные ассеты
├── cards/              # Исходная текстовая база Гримуара (Markdown/TXT)
│   ├── 0_basis/        # Основы контура
│   ├── 1_somatics/     # Телесное наблюдение
│   ├── 2_cognitivism/  # Внимание и мышление
│   └── 3_isolation/    # Сенсорная и цифровая депривация
├── backups/            # Резервные копии этапов разработки
└── launcher.js         # Автозапуск backend + ngrok-туннель + Telegram бот
```

- **Backend:** Node.js, Fastify, SQLite (`better-sqlite3` / `sqlite3`). Быстрый отклик, валидация `initDataUnsafe` из Telegram, сессии по PIN-коду.
- **Frontend:** Чистый Vanilla JS без тяжелых фреймворков. Canvas 2D для процедурной пиксельной анимации и гидродинамики. Полное сохранение в `localStorage`.
- **Bot:** Python 3 + Aiogram 3. Бесшовное открытие WebApp внутри Telegram.
- **Инфраструктура:** Автоматический туннель Ngrok для мгновенного доступа через интернет.

## 3. ЧТО УЖЕ ПОЛНОСТЬЮ РЕАЛИЗОВАНО (v0.3a)

### 🔒 3.1. Терминал Защиты // ГОСТ-КБ-181-СПЕЦ (Шлюз Авторизации)
- **Индустриальная стойка безопасности**:
  - Полный доступ к функционалу заблокирован до ввода пин-кода.
  - Верхний аквариум и все разделы скрыты до успешной верификации.
  - Шапка телеметрии (`SYS_ONLINE // KB-181`, `NODE_ID: #09-SU`, плашка `● ТРЕВОГА-0`, счетчики джиттера и энтропии).
- **Моноширинный визуализатор слотов**:
  - 4 крупных ячейки (54×62 px) с состояниями `_`, `■`, `·`.
  - Зеленый строб-индикатор при успешной авторизации, красная подсветка с вибрацией и встряской при неверном векторе.
- **Полноразмерная клавиатура 3×4**:
  - Кнопки `[ 1 ]`...`[ 0 ]`, клавиша очистки `[ СБРОС ]`, клавиша стирания `[ ⌫ ]`.
  - Поддержка физической клавиатуры ПК.
  - Тактильная виброотдача (**Telegram Haptic Feedback**).
- **Живой системный лог телеметрии (`#sys-log`)**:
  - Моноширинный лог с таймштампами `> HH:MM:SS`, фиксирующий каждый шаг оператора.
  - Индикатор буфера ввода: `[ ■ ■ □ □ ] 50%`.
  - Кнопка `[ ! ЭКСТРЕННЫЙ СБРОС СЕССИИ ! ]` и кинематографичный CRT-сканлайн.

### 🏛️ 3.2. Навигационная система «БАЗИС» и Главное Меню
- **Нижний док**:
  - `[ БАЗИС / ΒΑΣΙΣ ]` — открывает контекстное терминальное меню навигации.
  - `[ ЛАБОРАТОРИЯ / ΕΡΓΑΣТΗΡΙОН ]` — мгновенный переход в био-резервуар тамагочи.
- **Главное Меню**:
  - Компактный модальный оверлей без скролла: быстрый доступ к Соматике, Когнитивистике, Изоляции, Инструментам, Лаборатории, Закладкам, Наблюдениям и Базису.

### 📖 3.3. Гримуар Знаний (База карточек)
- **Разделы**:
  1. `[01] СОМАТИКА` (калибровка телесных реакций).
  2. `[02] КОГНИТИВИСТИКА` (паттерны внимания, расфокус).
  3. `[03] ИЗОЛЯЦИЯ` (сенсорная тишина, цифровой пост).
  4. `[i] БАЗИС` (основы и архитектура проекта).
- **Формат каждой карточки**: *Тезис → Фиксация сигнала → Действие оператора → Критерий выхода*.
- **Подкатегории** (`Классика`, `Эзотерика`, `Квантовая`) с заглушками калибровки (`ДОСТУП ОГРАНИЧЕН // b181`).
- **Закладки**: сохранение важных протоколов в локальное избранное.

### ⚡ 3.4. Интерактивный хаб инструментов
1. **§01 // Калькулятор талой воды**:
   - Расчет фракционного вымораживания (отделение дейтериевого льда, получение легкой биологически активной фракции).
2. **02 // Утренний расклад Таро**:
   - Техно-архетипическая калибровка вектора дня (22 Старших Аркана, переосмысленные через призму системного внимания).
3. **03 // Био-ритм дыхания (4-4-4-4)**:
   - Квадратный таймер вегетативной стабилизации (Вдох 4с — Задержка 4с — Выдох 4с — Пауза 4с) с индикатором прогресса и счетчиком выполненных циклов.
4. **04 // Журнал инцидентов b181**:
   - Лог телеметрии аномальных отклонений, сканирование джиттера и рассинхронизации контура.
5. **05 // Калькулятор фаз сна**:
   - Расчет 90-минутных циркадных циклов («уснуть прямо сейчас» или рассчитать оптимальное время отбоя к утреннему подъёму).

### 📝 3.5. Наблюдения (Источник & Послание)
- **1 — ИСТОЧНИК (Локально)**:
  - Автономная записная книжка оператора (`localStorage`) для фиксации гипотез, инсайтов и соматических реакций.
- **2 — ПОСЛАНИЕ (Сервер)**:
  - Форма отправки зашифрованных рапортов на сервер контура (Fastify + SQLite). Администратор видит все сообщения в БД.

### 🐱 3.6. Кибер-Симбионт CAT181b (v1.1-alpha)
1. **Интерактивный симбионт в верхней панели (`#cat-header-container`)**:
   - Позиционирован прямо под системной строкой меню в компактном формате (высота 42px).
   - Стилизованная пиксельная кибер-кошка CAT181b: угольно-черная шерсть, яркие изумрудно-мятные кибер-глаза (`#8fe09b`), сигнальный красный ошейник с золотым жетоном (`#d7232d`).
   - Кликабельна: при тапе издает процедурный кошачий синтезированный звук (мяу / чип-писк) + тактильный haptic-отклик и временно переключается на реакцию активности/выглядывания.
2. **Экран «ЛАБОРАТОРИЯ» (`#view-terrarium-lab`)**:
   - **Карточка чипа `[CHIP: CAT181b] S-A TERMINAL`**:
     - Аутентичный корпус микропроцессора с контактными ножками `| | | | | | | | |`.
     - 3 режима стилизованной анимации:
       - `[ 01. НАБЛЮДЕНИЕ ]` (`cat_sit.png`): базовое состояние покоя, покачивание хвоста, внимательный взгляд.
       - `[ 02. ВЫГЛЯДЫВАНИЕ ]` (`cat_peek.png`): осторожное выглядывание из-под края терминала.
       - `[ 03. АКТИВНОСТЬ ]` (`cat_action.png`): разминка кинематики, потягивание и проверка приводов.
     - **Интерактивные действия ухода (Тамагочи-контур)**:
       - `[ 🐟 ПОКОРМИТЬ ]`: синтез хруста корма (`playCatCrunch`), прирост био-синхронизации.
       - `[ 🧶 ПОИГРАТЬ ]`: тройной гармонический колокольчик (`playCatPlay`), режим активности.
       - `[ 🖤 ПОГЛАДИТЬ ]`: низкочастотная вибро-модуляция мурлыканья ~68 Гц (`playCatPurr`).
       - `[ 🧹 САНИТАРИЯ ]`: очистка буфера и профилактика чипа.
   - **Звуковой движок (`frontend/audio.js`)**:
     - 100% процедурный синтез звуков через Web Audio API (0 КБ внешних файлов).
     - Механические герконовые клики клавиатуры, тумблер рубильника, импульсный био-резонанс, кибер-кошачий синтез (Purr, Meow, Crunch, Play).

## 4. ЧТО МЫ ПЛАНИРУЕМ / ДУМАЕМ ВВЕСТИ (ROADMAP)

### 🧩 4.1. Развитие Кибер-Симбионта и Лаборатории
- **Эволюция и кибер-модификации**:
  - Покупка и установка внешних модулей за накопленные импульсы `⚡` (титановые накладки, улучшенные световоды, суб-процессор фильтрации).
  - Фазы роста/калибровки симбионта (b181-v1 → b181-v2).
- **Связь Симбионта с реальным Оператором**:
  - Выполнение оператором реальных практик (например, завершение 4 циклов дыхания 4-4-4 или расчет и выпивание талой воды) дает симбионту мгновенный буст тонуса и редкие импульсы.
- **Мини-игры в Лаборатории**:
  - Протокол «Калибровка частоты сонара» (попадание в ритмическую волну для добычи кристаллов данных).

### 📚 4.2. Расширение Гримуара и Контента
- **Новые разделы**:
  - `4_nutrition` (Нутрицевтика, электролиты, протоколы интервальной паузы).
  - `5_circadian` (Световая гигиена, утренний спектр, снижение синего света).
- **Разблокировка заблокированных веток**:
  - Снятие заглушек `[b181 // ОГРАНИЧЕНИЕ ДОСТУПА]` для подразделов «Квантовая» и «Эзотерика» при достижении определенного уровня импульсов или вводе секретных кодов.

### 🛠️ 4.3. Новые инструменты для Оператора
1. **Генератор акустической изоляции (Audio Noise)**:
   - Процедурный синтез белого, розового и коричневого шума через Web Audio API прямо в терминале для отсечения фоновых шумов офиса/города.
2. **Трекер цифровой депривации**:
   - Таймер «глубокого погружения» (уход в оффлайн на 30/60/120 минут без переключения вкладок).
3. **Дневник фаз и качества сна**:
   - Сохранение утренней оценки самочувствия био-датчика после пробуждения по калькулятору фаз.

### ⚙️ 4.4. Системные и серверные улучшения (Фаза 2)
- **Хард-капы на отчёты (`daily_report_caps`)**:
  - Ограничение на отправку посланий (максимум 3 в сутки), чтобы оператор формулировал только самое существенное и не забивал контур информационным шумом.
- **Циклы дисциплины (`focus_cycles`)**:
  - Программы монолитного фокуса на 3, 7, 21 или 28 дней с ежедневной отметкой прогресса.
- **Облачная синхронизация**:
  - Возможность безопасного сохранения прогресса тамагочи и заметок в облако через Telegram Cloud Storage или учетную запись оператора на сервере.
